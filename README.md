## 배정 기준

위에서부터 우선 적용합니다. 작업 유형은 초기 배정 기준이며, 검증 결과에 따라 재배정합니다.

| 조건 | 결정 |
|---|---|
| 사용자 지정 담당·외부 전송 제한 | 지정과 제한 우선; 실행 불가 시 원인 반환 |
| 목표·완료 조건 또는 참조 대상 불명확 | 관련 문맥 보완; 배정에 필요한 항목만 확인 |
| 로컬 처리 가능, 입력·출력이 가용 메모리 범위 | Qwen3.6-35B-A3B: 자료 분석·요구사항 정리·초안 |
| 저장소 수정·오류 재현·테스트 실행이 핵심 | Codex 작업자 우선 |
| 설계 대안·상충 조건·문서 일관성 검토가 핵심 | Claude 작업자 우선 |
| 복합 작업 | 산출물·의존성 단위로 분리; 필요한 단계만 인계 |
| 검증 실패 | 실패 근거로 기존 담당 수정 또는 다른 담당 재배정 |

## 운영 기준

| 구분 | 적용 기준 |
|---|---|
| 라우팅 | Qwen3.5-4B는 담당 선택·재배정 전용; 직접 작업 금지 |
| 인계 | 원문·관련 문맥·제약·완료 조건·기존 결과·남은 한도 전달; 요약으로 원문 대체 금지 |
| 실행 | 등록된 작업자와 모델 연결 확인; 부모 4B 상속·없는 담당 실행 차단 |
| 메모리 | 4B 상주 우선, 35B 필요 시 로드; 로컬 추론 동시 실행 1부터 검증 |
| 메모리 부족 | 상태 보존 후 유휴 모델·캐시 해제; 클라우드 전환은 전송 제한 재확인 후 재배정 |
| 검증 | 실행 가능한 검사와 완료 조건으로 통과·실패·미확인 구분; 4B 의견만으로 통과 금지 |
| 재시도 | 실패 원인·수정 방향·잔여 한도 확인; 새 근거 없거나 한도 소진 시 중단 |
| 반환 | 검증된 작업자 결과 보존; 미확인 항목은 완료로 표시하지 않음 |
